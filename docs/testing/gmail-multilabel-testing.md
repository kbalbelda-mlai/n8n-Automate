# Gmail Multi-Label Workflow — Testing

## Formal Test matrix

| ID | Scenario | Labels | Attachments | Expected behavior | Result |
|---|---|---|---:|---|---|
| G01 | No attachment | L01 | 0 | Log one row; no upload; `NO_ATTACHMENT` | PASS |
| G02 | Single PDF | L02 | 1 | Upload file and log one row | PASS |
| G03 | Multiple mixed attachments | L03 | 2 | Store both files; log one row | PASS |
| G04 | Fourth-label routing | L04 | 2 | Correct label routing and uploads | PASS |
| G05 | Multiple labels, no attachment | L01 + L03 | 0 | Preserve both labels; log one row | PASS |
| G06 | Multiple labels with attachment | L02 + L04 | 1 | Preserve both labels and store file | PASS |
| G07 | Batch polling | L01 | 1 | Process correctly when several emails arrive before one poll | PASS |
| G08 | Filename collision | L02 | 1 | Preserve original; create suffixed filename | PASS |
| G09 | Three attachments | L03 | 3 | Store all three; log one row | PASS |
